# Python Scripts

This repository contains ready-to-sync Python utility scripts.

## Purpose

The repository is intentionally kept minimal so only files placed in the `Python/` folder are tracked and published.

## Current script

- `Python/date_format.py` — formats dates and times using common Python date format directives.

## Workflow

- Keep work-in-progress files outside the repo until they are ready.
- Move finished scripts into the `Python/` folder before committing and pushing.
- Use GitHub for only the reviewed, ready-to-share versions.

## Usage

Run the script from the repository root:

```bash
python Python/date_format.py --list
python Python/date_format.py --format %Y-%m-%d
```
